## Skills

Treat the available skill catalog as authoritative guidance for task-specific workflows.

* Before beginning substantive work, inspect the skill catalog and load any skill whose description materially applies to the task.
* Load applicable skills before writing code, modifying files, or running task-specific commands, using the environment's supported skill-loading mechanism.
* Match skills by their documented descriptions; never assume that a particular skill exists or has a specific name unless it appears in the catalog.
* A detailed task brief, repository documentation, or this file does not replace applicable skill instructions.
* When applicability is reasonably uncertain, prefer loading the skill; do not load unrelated skills merely because they are available.
